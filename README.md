# tw-airquality-mini

Mini data analysis project for Taiwan air quality data.

## How to run

1. Activate the virtual environment: `.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Unix).
2. Install dependencies: `pip install -r requirements.txt`.
3. Place raw CSV files into `data/raw/`.
4. Launch JupyterLab: `jupyter lab` and open `notebooks/01_explore.ipynb`.
